
To-Do List App - Description
The To-Do List App is a simple and efficient task management tool that helps users organize their daily activities. It allows users to:
Add Tasks with categories (Personal, Work, Shopping)
Set Priorities (Low, Medium, High) & Due Dates
Mark Tasks as Completed with a checkbox
Edit or Delete Tasks easily Enable Dark Mode for a better viewing experience
With a clean and interactive interface, this app ensures smooth task management while keeping users productive.
